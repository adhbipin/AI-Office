# AI Office

An interactive 3D isometric office visualization where multiple local AI agents (powered by Ollama) collaborate on software development tasks in real-time.

## 🚀 Features
- **Local AI Agents:** 6 specialized agents (PM, UI/UX, Frontend, Backend, QA, DevOps) using Llama 3 and CodeLlama.
- **3D Visualization:** Real-time 3D office built with Three.js featuring animated avatars and message particles.
- **Automated Workflow:** Agents analyze tasks, write code, and generate documentation autonomously.
- **Workspace Viewer:** Live view of files generated by the agents in the local workspace.

---

## 🛠️ Prerequisites

1.  **Ollama:** Install from [ollama.ai](https://ollama.ai/)
2.  **Models:** Pull the required models:
    ```bash
    ollama pull llama3:8b
    ollama pull codellama:latest
    ```
3.  **Python 3.11+**
4.  **Modern Web Browser** (Chrome/Firefox recommended)

---

## 💻 Installation & Setup

### 1. Clone the Repository
```bash
git clone https://github.com/adhbipin/AI-Office.git
cd AI-Office
```

### 2. Backend Setup
```bash
cd backend
pip install -r requirements.txt
```

---

## 🏃‍♂️ How to Run

### Step 1: Start the Backend Server
In your terminal, navigate to the `backend` folder and run:
```bash
uvicorn main:app --reload --port 8000
```
The server will start at `http://127.0.0.1:8000`.

### Step 2: Open the Frontend
1. Navigate to the `frontend` directory.
2. Open `index.html` in your web browser.
3. You should see a green "Connected to Backend" status bar if everything is working correctly.

---

## 🎮 How to Use
1. **Enter a Task:** In the right-hand panel, type a task like *"Build a simple portfolio website"* or *"Create a Python REST API for a blog"*.
2. **Watch the Office:** 
   - The **Project Manager (PM)** will start by analyzing the task.
   - You will see **Speech Bubbles** above the avatars and **Message Particles** flying between desks as they collaborate.
   - **Avatar Bobbing:** Agents bob faster when they are actively "thinking."
3. **Check Output:** 
   - Watch the **Live Feed** for detailed logs of agent thoughts.
   - Use the **Workspace Viewer** at the bottom right to see the actual files being created in real-time.

---

## 📂 Project Structure
- `/backend`: FastAPI server and custom agent orchestration logic.
- `/frontend`: Three.js 3D scene and UI panel.
- `/workspace`: The shared folder where agents read and write all code/files.
